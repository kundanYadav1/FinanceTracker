## 1. Objective

Remove installed packages that the MVP design does not use, and confirm that the release build requests no runtime permissions.

## 2. Background and Context

DEP §2 lists `expo-notifications`, `expo-glass-effect`, `@expo/ui`, `expo-image`, `expo-font`, `expo-web-browser`, `expo-device` as unused. `expo-notifications` may add notification permissions to the Android manifest, which contradicts SEC §2 ("the MVP requests no runtime permissions"). OD-17 recommends one cleanup task that keeps `expo-secure-store`.

## 3. Requirements

1. Remove exactly the packages the OD-17 decision lists. Default (recommended) list: `expo-notifications`, `expo-glass-effect`, `@expo/ui`, `expo-image`, `expo-font`, `expo-web-browser`, `expo-device`.
2. Keep `expo-secure-store` and its `app.json` plugin entry. Keep `expo-linking` (router peer).
3. If OD-13 confirms "web unsupported", leave `react-native-web`/`react-dom` installed unless OD-13 explicitly says to remove them (expo-router may still need them for typed-route tooling); record the outcome.
4. After removal, no source file imports a removed package.
5. Run a native prebuild in a temporary directory (`npx expo prebuild --platform android --no-install` into a scratch copy, or inspect the EAS build log) and confirm the merged Android manifest has no `POST_NOTIFICATIONS` or other runtime permission. Do not commit generated `android/` folders.

## 4. Scope

### Included
- `npm uninstall` of approved packages; manifest permission check.

### Excluded
- Adding any dependency.
- Upgrading any package.

## 5. Files to Create or Modify

| File Path | Action | Purpose |
|---|---|---|
| `package.json` | MODIFY | Remove approved packages |
| `package-lock.json` | MODIFY | Regenerated by npm |
| `app.json` | MODIFY (only if a removed package has a plugin entry) | Remove its plugin entry |

## 6. Implementation Instructions

1. `grep` for each package name in `src/` and config files; stop if any is still imported.
2. `npm uninstall <pkgs>`.
3. `npx expo install --check` and `npx expo-doctor`.
4. Perform the manifest check in §3.5 and paste the permission list into the completion report.
