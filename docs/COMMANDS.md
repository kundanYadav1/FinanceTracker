# Standard Command Reference

## Development

### Start development server
```bash
npx expo start
```

### Validate Expo project
```bash
npx expo-doctor
```

### Lint
```bash
npx expo lint
```

### Type check
```bash
npx tsc --noEmit
```

## Testing

### Unit/component tests
```bash
npm test
```

## Native Builds

### Android native development build
```bash
npx expo run:android
```
